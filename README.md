## 📖 关于海德格尔

**Martin Heidegger**（1889-1976）是20世纪最重要的哲学家之一，对现代哲学产生了深远的影响。他的主要哲学成就包括：

- **存在论转向** - 重新审视存在（Being）的问题
- **现象学方法** - 发展和深化了现象学研究方法
- **诗性思维** - 强调语言与存在的关系
